# ⏱️ Console Stopwatch em C#

Aplicação de cronômetro via console desenvolvida em C# (.NET) para prática de controle de fluxo, manipulação de texto e gerenciamento de tempo de execução.

## 📌 Funcionalidades
* Contagem regressiva/progressiva configurável pelo usuário.
* Suporte a diferentes unidades temporais:
  * **s**: Segundos (ex: `15s`)
  * **m**: Minutos (ex: `2m`)
  * **h**: Horas (ex: `1h`)
* Menu interativo com rotina de encerramento seguro.
* Tratamento de entradas do usuário e validação de formatos.

## 🛠️ Tecnologias e Conceitos Utilizados
* **C#** (.NET)
* Manipulação de Strings (`Substring`, fatiamento de índices)
* Conversão e parsing de tipos numéricos
* Controle de execução com `Thread.Sleep` e laços de repetição
* Modularização via funções estáticas
